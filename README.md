# 🐩 貪吃狗點心屋：婷婷的糖果花園

![婷婷的糖果花園遊戲封面](assets/backgrounds/bg_cover_3d.png)

**甜點從天而降，婷婷的點心車準備開動！**

走進色彩繽紛的糖果花園，陪貪吃的婷婷接住馬卡龍、甜甜圈和草莓蛋糕。在 **60 秒**內裝滿點心車、累積連擊，挑戰你的最高分！不過要看清楚——混在甜點中的朱古力，可不能照單全收。🍫

## 🍬 一局 60 秒，還想再玩一局

- **接得開心，看得見！** 婷婷會隨著接到的食物，切換平常、開心和暈眩三種表情。
- **甜點接不停，連擊更高分。** 連續接住甜點累積 COMBO，達到 10 連擊可享 1.5 倍得分。
- **一支棒棒糖，啟動甜蜜狂熱！** 雙倍得分、甜點磁鐵，還能擋開朱古力。
- **全螢幕投入糖果世界。** 支援滑鼠、鍵盤和觸控，電腦、手機都能玩。
- **隨時開玩，離線也可以。** 不用安裝、不用註冊，最高分會記錄在目前的瀏覽器。

## ▶️ 點心時間，現在開始

1. 把整個遊戲資料夾下載或解壓縮到電腦。
2. 雙擊 **[index.html](index.html)**，用瀏覽器開啟。
3. 按下 **「開始遊戲」**，幫婷婷接住第一份甜點！

遊戲會填滿視窗，開始時會嘗試進入全螢幕。你也可以按右下角的「全螢幕」切換，按 `Esc` 退出；右下角亦可開關音效。

## 🎮 婷婷往哪走，由你決定

| 裝置 | 操作方式 |
| --- | --- |
| 滑鼠 | 左右移動滑鼠，婷婷便會跟著走 |
| 鍵盤 | 按 `←`、`→` 或 `A`、`D` 左右移動 |
| 手機／平板 | 在遊戲畫面上用手指左右拖曳 |

每局有 **3 顆心**。時間結束或生命值歸零，便會結算得分和最高連擊。準備再挑戰一次？按「再玩一次」就能重新出發！

## 📁 把糖果花園帶著走

請保留以下檔案在同一個資料夾，便可直接開啟遊玩：

```text
婷婷的糖果花園/
├── index.html       遊戲入口
├── game.css         畫面與版面樣式
├── game.js          遊戲邏輯與音效
└── assets/
    ├── backgrounds/ 封面與花園背景
    └── sprites_png/ 婷婷與甜點圖片
```

想替糖果花園換個造型？替換 `assets/` 內相應的 PNG 圖片，保留原本檔名，再重新整理遊戲即可。
